# Hubitat MCP AI release-note index

The maintained add-on keeps one release-note file per published version using:

```text
CHANGELOG-<version>.md
```

## Current release

- [0.10.319](CHANGELOG-0.10.319.md)

When `config.yaml` changes version, the same pull request must:

1. add `CHANGELOG-<version>.md`;
2. update the current-release entry above;
3. keep the root repository component version aligned.

The older monolithic `CHANGELOG.md` is retained as historical material but is not the current release index.
