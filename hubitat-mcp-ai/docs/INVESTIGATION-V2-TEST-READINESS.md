# Investigation V2 — archived experimental test programme

**Retired in v0.18.242.** The standalone V2 browser page, test-token and
opt-in options, HTTP test API and browser-access cookie have been removed.
The historical commands and test matrix in earlier revisions of this
document are **not instructions for the current add-on**.

The original HomeBrain Main Ask/Chat is now the single user-facing
investigation and device-control experience. It retains the
source-attested V2 evidence projection, source-time chronology, identity
and read-only provenance safeguards and selected offline regression tests.
The separate V2 test agent and UI are no longer supported as public routes.

## Current acceptance programme

Run the original HomeBrain Main Ask with the explicit incident and
exact target names. Check that all independently returned switch ON/OFF
transitions appear in the final chronological source timeline, that the
answer distinguishes a reported ON from a later setLevel brightness
adjustment, and that no sensor correlation or reporting bridge is
promoted into a proven external initiator.

For the historical Bathroom comparison, the attached Hubitat device
histories establish ON/OFF pairs around 03:04, 03:40, 03:46 and 07:12
on 30 October 2026. The 07:15 School Run event is a brightness/mode
change, not a new Bathroom Light 1 ON. The 02:18 and 02:52 events in the
independent Claude report appeared in Hubitat Logs and **cannot**
be fabricated from an incomplete individual device event stream.
Device history truncation, incident-time log coverage, and sensor
provenance must be stated accurately.

Internal V2 regression tests are retained to prevent regressions in
permission boundaries, identity attestation and typed source evidence.
V2 is not a second production assistant or a replacement for the
original HomeBrain MCP tool loop.
