## Implemented V2-only correction

- Add `read_only_receipt_fallback.py`: **bounded, original-MCP-receipt-only** partial textual summary when the model's later read-only investigative answer is empty, an actual model/transport error occurs after successful reads, or the time-budget finalization returns nothing. Use *only* successful, parseable original native device-event rows with consistent device ID and attribute, offset-aware event instants in configured IANA timezone, and state values present in receipts. Ignore separate location mode entries, current inventory, commands as outcome state rows, failed reads, invalid timestamps and unsupported values. De-duplicate overlapping event rows, distinguish discrete reported values from continuous or physically verified operation, and select bounded distinct positive observations across source-covered devices, without assigning a causal initiator or choosing a tool.
- This is an **emergency answer-failure path only**; it does NOT rewrite successful model answers, infer a focal target or controller reason, add a model round, request an MCP read, change any scheduled action, bypass any native writer or convert a write into a read-only success. Only available for non-action causal/historical/source verification investigations after already successful original read-only state-event receipts. It is not a fake source or substitute for complete investigation.
- The reply is clearly titled **“Investigation incomplete — source-only partial result”** and says exactly that source-reported state/time evidence exists but the initiating cause and physical outcome remain unverified in this partial result.
- Add PRIVATE completion metadata `answer_fallback_status` and scoped `response_success_scope`. A useful partial factual answer is returned to the UI instead of the generic error while the fallback field makes the model's failure explicit.
- Model skill efficiency guidance now encourages reusing original scope, avoiding repeated broad overlapping event pages, and publishing concise source-backed positive observations when no discriminating read is useful. No deterministic retry limiter, forced tool, invented causal logic, manual action fastpath or arbitrary round cap.
