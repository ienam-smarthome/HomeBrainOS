# Install on Home Assistant OS

1. In Home Assistant, go to Settings → Add-ons → Add-on Store → ⋮ →
   Repositories, and add:

   ```text
   https://github.com/ienam-smarthome/HomeBrainOS
   ```

2. Open **Hubitat MCP AI** in the add-on list.
3. Follow the [setup steps](../hubitat-mcp-ai/README.md#setup) to install and
   configure the Hubitat MCP Rule Server and connect this add-on to it.
4. Install and start the add-on.
5. Open the Web UI from the Home Assistant sidebar or the configured port.
