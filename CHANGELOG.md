# HomeBrainOS changelog

The repository-level changelog previously documented the retired Maker-API dashboard and its `1.x-alpha` releases. That implementation is no longer shipped or maintained.

## Maintained release history

The active Home Assistant add-on is **Hubitat MCP AI**. Its release notes are stored alongside the add-on as versioned files:

```text
hubitat-mcp-ai/CHANGELOG-<version>.md
```

Start with the highest `0.10.x` version in that directory for the latest release notes. The current maintained component and version are also listed in the repository `README.md` and `hubitat-mcp-ai/README.md`.

## Legacy history

The former Maker-API dashboard changelog remains available through this file's Git history. It is retained as project history only and must not be treated as documentation for the current runtime.
